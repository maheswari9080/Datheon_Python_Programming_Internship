System Architecture

Engineered for complete component decoupling. The static dashboard provides unified navigation while Python apps run directly in terminal environments.

Zero External Dependency

All core applications operate 100% on the standard Python 3.10+ library, eliminating brittle third-party dependencies.

Offline-First Resilience

Every data-driven component includes structured offline fallback datasets, guaranteeing execution in air-gapped environments.

Strict Filesystem Guardrails

File operations strictly validate target directories, disallowing accidental execution on system roots or repository source code.

Truthful Data Reporting

Explicit price sources prevent confusion between real-time quotes, manual inputs, and offline reference feeds.
