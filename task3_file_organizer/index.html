Task 03: Automated File Organizer & Cleanup Utility

A safe filesystem automation utility that scans directories and organizes files into 8 semantic categories using pathlib and shutil with dry-run simulation and path safety validation.

8 Semantic Categories

Classifies Documents, Images, Videos, Audio, Archives, Code, Spreadsheets, Presentations, and Other.

Filesystem Safety Guard

Rejects filesystem root drives (C:\, /), system directories, and the project repository itself.

Collision Management

Configurable collision resolution: rename (appends _1), skip, or overwrite.

12 / 12 Unittests

All tests execute in temporary sandboxes, verifying dry-run neutrality and collision handling safely.

Terminal Launch Command

Bash / PowerShell
# Dry-Run Simulation (Recommended First) python task3_file_organizer/organizer.py --target "C:\Users\YourName\Downloads" --dry-run # Live Execution with Confirmation python task3_file_organizer/organizer.py --target "C:\Users\YourName\Downloads" # Non-Interactive Automation python task3_file_organizer/organizer.py --target "C:\Users\YourName\Downloads" --collision rename --non-interactive # Run Automated Test Suite python -m unittest discover -s task3_file_organizer/tests -p "test_*.py" -v
