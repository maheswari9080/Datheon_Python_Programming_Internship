Task 04: Rule-Based Interactive FAQ Assistant

A deterministic conversational terminal assistant built with pure Python standard library regex and token matching to answer student inquiries from verified JSON FAQ datasets without AI hallucination.

Verified FAQ Schema

Loads from data/sample_faq.json, adapting to greetings and FAQ question-answer pairs with offline fallback.

Token Scoring Engine

Combines exact phrase matching, regex, and Jaccard token similarity so specific questions outrank generic queries.

Truthful Non-Fabrication

Never invents business hours, contact numbers, or policies not present in verified dataset.

14 / 14 Unittests

Fully verified across greeting classification, FAQ retrieval, exit commands, malformed JSON recovery, and fallbacks.

Terminal Launch Command

Bash / PowerShell
# Interactive Chat Session python task4_chatbot/chatbot.py # Non-Interactive Query python task4_chatbot/chatbot.py --query "When will I receive my certificate?" # Run Automated Test Suite python -m unittest discover -s task4_chatbot/tests -p "test_*.py" -v
