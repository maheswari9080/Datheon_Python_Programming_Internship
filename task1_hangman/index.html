Task 01: Hangman Word Guessing Challenge

An interactive console word game built in Python featuring candidate filtering, 7 ASCII gallows stages, a 6-mistake ceiling, and duplicate-guess immunity.

Candidate Filtering

Loads from data/words.txt (Google 10,000 words list), filtering 4-10 letter uppercase words with offline fallback.

ASCII Gallows Progression

Renders 7 visual stages from clean gallows (0 mistakes) to full hangman (6 mistakes, loss condition).

Zero Penalty on Repeats

Prevents duplicate or invalid character inputs from decrementing remaining guess attempts.

18 / 18 Unittests

Fully verified with Python's built-in unittest framework across all victory, defeat, and edge cases.

Terminal Launch Command

To play the game, launch the Python script in your terminal environment:

Bash / PowerShell
# Interactive Play python task1_hangman/hangman.py # Test Mode with Deterministic Secret Word python task1_hangman/hangman.py --word PYTHON # Run Automated Test Suite python -m unittest discover -s task1_hangman/tests -p "test_*.py" -v

Component Architecture

File Role Description
hangman.py CLI Controller Interactive loop, input handling, replay session management.
game_engine.py Pure Engine Decoupled state machine tracking mistakes, guesses, win/loss rules.
graphics.py ASCII Renderer 7 gallows stages, banners, masked word presentation.
