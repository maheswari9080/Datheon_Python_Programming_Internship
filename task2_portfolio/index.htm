Task 02: Stock Portfolio Performance Tracker

A terminal-based investment portfolio valuation tool computing cost basis, market value, and gain/loss metrics with RFC 4180 CSV export and provider-independent price handling.

S&P 500 Constituent Lookup

Validates tickers against 503 constituents in data/constituents.csv with corporate names and GICS sectors.

Provider-Independent Pricing

Supports offline reference quotes (sample_prices.json), manual price inputs, and optional live quotes via yfinance.

Partial Valuation Transparency

Strictly excludes unquoted holdings from total market valuations, preventing misleading under-reporting.

14 / 14 Unittests

Fully validated across financial formulas, multi-holding totals, edge cases, and CSV schema persistence.

Mathematical Valuation Engine

Invested Capital

Cost = Buy_Price × Quantity

Current Market Value

Value = Current_Price × Quantity

Absolute Return

Gain/Loss = (Current_Price - Buy_Price) × Quantity

Percentage Return

% = ((Current_Price - Buy_Price) / Buy_Price) × 100
